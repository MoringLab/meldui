## Captured media framing experiment

A bounded natural-language media request through `auto/claude-sonnet` reported actual model `openai/gpt-oss-120b`. It produced a correct carousel/left/Markdown media object inside a pretty-printed JSON code fence, so strict decoding correctly kept it as literal Markdown. The opt-in framing normalizer unwraps only a fully validated Engine/A2UI control object/array; ordinary JSON examples, unknown versions and prototype keys stay literal. Replaying this captured output changed that one case from fail to pass, with `fenced-control:1` logged and no additional model call. A second calculator request timed out within the host latency budget. These two rows do not establish a general quality rate.

Safe hybrid normalization buffers an attempt until completion so it can validate whole fenced JSON. This trades incremental first display for framing recovery; standard/off still streams immediately. It is an operator-controlled profile, not an adopted global default or measured latency improvement. Raw/normalized artifacts are `artifacts/eval/feature-smoke.json` and `artifacts/experiments/framing-capture.json`.
