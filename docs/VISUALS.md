# Visual and learning authoring

The core catalog now contains 50 validated components. In addition to the original layouts, inputs and media it includes Confirmation, ControlPanel, Stat/StatGroup, Legend, Formula, Annotation, Walkthrough, Quiz, Timeline, Playback, SvgScene, Plot, RouteMap and Simulation. All three kits map the additive components. Existing 30 A2UI replays remain unchanged.

`learningPatterns` contains eleven semantic authoring patterns: learning, calculator, comparison, simulator, dashboard, walkthrough, practice, game, itinerary, form and media-led. `definePattern()` validates host authoring guidance; `availablePatterns()` filters its referenced components for the target. Pattern guidance belongs in the prompt/kit guide, not executable model code. Wide Showcase workspaces use Grid for visual/controls; narrow containers stack them. Input labels, units, reset and data-table/text alternatives remain available.

Expressions are pure JSON AST. `add`/`mul` accept multiple operands, `sub/div/mod/pow` two, aggregates one array, `get` an integer array index. Added math, range/map/filter/reduce/scan/series and number formatting have depth 16, 256 AST nodes, 10,000 operation visits and a cumulative 1,000 array-iteration budget. `$item`, `$index`, `$acc` are lexical iteration locals. Conditions evaluate only the selected branch. A budget failure is a component diagnostic.

`rng(seed, drawIndex)` is random-access deterministic 32-bit mixing, not ambient Math.random. TS/Dart parity vectors pin it. Golden probabilistic reference calculations deliberately use an independent generator. `Ticker` has fixed manual steps, speed, visibility/reduced-motion gates, snapshot restore and disposal. Native Playback provides manual step/reset; continuous animation is declared unavailable there.

SvgScene permits only group, rect, circle, ellipse, line, polyline, polygon, path, text and bounded repeat. Attributes, transforms, gradients and clip IDs are whitelisted. No HTML, foreignObject, remote hrefs or style strings are accepted. Scenes cap depth at 12 and visits/elements at 300, including repeat expansion. Drawable primitive click/hover actions use the normal dispatcher; web drag paths map to 0–1 with keyboard arrows. Native drag is unsupported; use Slider. RN hover falls back to touch, Flutter exposes scene action buttons. Group actions and repeat-local action context are not advertised; use primitive actions with surface paths or explicit controls. There is no GPU/3D engine.

Plot implements line/parametric/scatter/area/histogram from bounded arrays on all platforms. Chart's multi-series, rolling window, reference lines, bands, logarithmic scale and stacked bars are web features; native prompts expose only their basic line/bar/scatter implementation. RouteMap uses a tile-free approximate projection and host actions for real location verification. No external map provider is enabled by default.

Trusted web simulations expose `createSimulation(module, seed, params)`: nBody (softened velocity-Verlet), cellular (discrete sand/water/fire motion), agents (food/prey/predator, births/deaths and inherited-trait mutation). Methods are `step`, `snapshot`, `restore`, `metrics`, `reset`, `pour`, `dispose`. Snapshots carry RNG draw index. Inputs are bounded; histories cap at 240 samples. Web auto-play pauses offscreen/hidden/reduced motion, caps eight steps with a 12ms check between steps and stops after 2,000 timer ticks. These are educational reference models, not validated scientific solvers. Native Simulation uses a declared text alternative; hosts may register a trusted native implementation.

The JSON Schema exporter converts draft-7 tuple `items` into 2020-12 `prefixItems` so upstream Dart validation reads the same viewBox contract. Kit, scene-data and user-input changes remain outside model transport. Scene revisions invalidate only the relevant bound node; the unrelated-sibling regression test remains in the suite.
