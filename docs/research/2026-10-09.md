# Research record

Access date: 2026-10-09. The approved implementation uses a restricted custom catalog and pinned upstream cores.

- [A2UI version/specification](https://a2ui.org/specification/v0.9.1-a2ui/): ordered declarative messages, flat component graphs, relative template scopes, local input updates. v0.9.1 is the chosen stable profile; v1 is not our compatibility target.
- [A2UI catalog guide](https://a2ui.org/guides/defining-your-own-catalog/): catalog identity determines compatibility. Keep component/function schemas and implementations aligned.
- [Dart core](https://pub.dev/packages/a2ui_core): reuse data, component and message models. Avoid depending on the WIP Flutter renderer.
- [AG-UI](https://docs.ag-ui.com/concepts/generative-ui-specs), [CUSTOM events](https://docs.ag-ui.com/concepts/events): agent transport is complementary to UI descriptions; expose optional integration.
- [Vercel AI SDK](https://ai-sdk.dev/docs/ai-sdk-ui/generative-user-interfaces): tool results map to trusted components. Avoid coupling the core to a chat framework.
- [json-render catalog](https://json-render.dev/docs/catalog), [OpenUI](https://github.com/thesysdev/openui): learn catalog-driven prompting and streaming inspection, without introducing a new syntax.
- [Open-JSON-UI documentation path](https://docs.copilotkit.ai/learn/generative-ui/specs/open-json-ui): independent current normative specification was not established; not used as the implementation contract.
- [OpenAI structured outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [Anthropic structured outputs](https://platform.claude.com/docs/en/build-with-claude/structured-outputs): provider JSON Schema subsets differ; runtime-validated NDJSON is the initial baseline.
- [Expo streaming fetch](https://docs.expo.dev/versions/latest/sdk/expo/): use expo/fetch for the native demo's streaming transport.
- [Flutter integration tests](https://docs.flutter.dev/testing/integration-tests), [Maestro platforms](https://docs.maestro.dev/get-started/supported-platform/react-native.md): common device flows plus widget/state assertions.
- [HTML iframe sandbox](https://html.spec.whatwg.org/multipage/iframe-embed-object.html#attr-iframe-sandbox), [CSP](https://www.w3.org/TR/CSP3/): isolation tools, not sufficient resource guarantees. Defer the escape hatch.

Small pre-implementation NDJSON probes reached three OmniRoute routes: cx/gpt-5.6-sol-medium, agy/claude-sonnet-4-6, agy/gemini-3.7-flash-medium. Those were connectivity probes, not quality benchmarks. Current evaluation writes separate structural validity results; a registered model ID does not establish callability or provider identity.
