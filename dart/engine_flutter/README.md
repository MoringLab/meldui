# Engine Flutter

Private A2UI SDK with 50 validated catalog components, three portable kits and ordered Markdown/surface/media answers. Use `UIRuntime.create()`, `AnswerSession`, `UIProvider` and `AnswerView`; the earlier `UISurface` integration remains supported. Dispose runtime/session subscriptions when the host unmounts. Wire compatibility is a restricted A2UI v0.9.1 profile using Engine's custom catalog ID.

Host-owned attachments resolve by ID. Galleries use native paging and enlargement; media can appear beside Markdown or above/below it, with stacking in narrow containers. GFM/math/code, typography, light/dark, local formulas/actions, bounded SVG scenes, plots, learning controls and approximate route maps share the TypeScript contract. Seeded expressions/history preserve local state across kit changes.

Continuous scene dragging/playback, advanced Chart features, trusted simulation modules and executable sandbox have explicit unsupported/fallback declarations on this renderer. Flutter audio and document previews use FileCard alternatives. Hosts supply authentication, asset storage/URL signing, downloads and real map/business APIs. No model keys, uploads, arbitrary HTML or remote modules belong in the app.

The independent `apps/flutter` demo and shared replay/Showcase fixtures exercise the SDK. Run `flutter analyze` and `flutter test`; Android native work uses the repository's resource mutex. The repository README, media composition contract, VISUALS.md and dated verification report document integration and remaining release gates. Packages stay private; no scientific, human learning-quality, iOS or production-isolation certification is claimed. Apache-2.0.
