# Engine

<!-- impeccable:product-schema 1 -->

## Platform
adaptive

## Stack
Approved: TypeScript, React web, React Native with Expo, and Flutter. A2UI v0.9.1 profile with v0.9 envelopes. Model calls use the local OmniRoute gateway.

## Users
Developers embedding agent-generated interactive interfaces in existing web services and mobile apps.

## Product Purpose
Render trusted component descriptions progressively, keep local interactions fast, and swap complete design-language kits without regenerating the interface.

## Operating Context
The reference lab offers prompts, fixtures, kit switching, diagnostics and replay. Showcase, service and studio surfaces demonstrate visual answers, host embedding and trusted custom components using authored fixture replays. Live AI generation quality has separate validation. Two independent Android apps prove native integration on the connected device.

## Capabilities and Constraints
Typed semantic components, interactive SVG scenes, Markdown, KaTeX and host-resolved media can compose one answer. Neutral and editorial kits remain the core reference languages; a brand kit demonstrates host implementation replacement. Hosts can register trusted custom components and choose their own theme, tools and surface framing. Local interactions and kit changes preserve answer state.

Generated HTML/CSS/JavaScript is a separate, explicitly opted-in web capability, disabled by default. Live widgets use host-approved resources and a host bridge with explicit readable and writable state paths. Host actions, data and media stay under host control. API credentials remain on the server. Native React Native and Flutter renderers accompany the web renderer; desktop implementations are later work.

## Brand Commitments
Approved working name: Engine. Neutral and editorial kits. Interface language is Korean with English technical documentation.

## Accessibility & Inclusion
Keyboard access, screen reader semantics, dynamic text sizes, reduced motion, and accessible alternatives for charts.
